# Kairós MVP 24h — Plan Maestro de Coordinación

> **Para workers agénticos:** usa `superpowers:executing-plans` o `superpowers:subagent-driven-development` para ejecutar este plan.

**Goal:** Construir un MVP demostrable de Kairós en 24 horas con 4 desarrolladores en paralelo, sin conflictos de integración.

**Architecture:** Monorepo con 4 streams independientes (backend, frontend, extensión, agente+ML) que se integran mediante contratos de API definidos en este documento. Cada desarrollador trabaja en su propio directorio y nunca modifica archivos de otro stream.

**Tech Stack:** Next.js 14 + FastAPI + Chrome Extension MV3 + Anthropic SDK + Supabase + pgvector

## ⚠️ Contratos de API — Fuente de Verdad

**Todos los devs deben respetar exactamente estos contratos. No modificarlos sin avisar al equipo.**

### URLs base (desarrollo local)
```
api-service:   http://localhost:8000
agent-service: http://localhost:8001
web:           http://localhost:3000
```

### Autenticación
Todos los endpoints de `api-service` y `agent-service` (excepto `/health`) requieren:
```
Header: Authorization: Bearer <supabase_jwt_token>
```
El token se obtiene del cliente Supabase en el frontend y la extensión.

## Flujo Demo End-to-End (lo que debe funcionar al final)

```
1. Usuario abre http://localhost:3000
2. Se registra con email/password (Supabase Auth)
3. Onboarding: completa PHQ-9 (9 preguntas) → completa GAD-7 (7 preguntas)
4. Ve el dashboard con métricas en cero (primera vez)
5. Instala la extensión de Chrome (modo desarrollador)
6. Navega por 2-3 sitios web durante 5 minutos
7. La extensión sync los eventos a http://localhost:8000/api/v1/events/batch
8. El dashboard muestra los sitios visitados y tiempo
9. Usuario abre el chat y pregunta: "¿Cómo estoy?"
10. El agente responde con insights basados en sus datos + activar un playbook
11. El agente sugiere un hábito
12. Usuario agrega el hábito → aparece en la sección de hábitos
13. Usuario marca el hábito como completado → ve su racha (1 día)
```
